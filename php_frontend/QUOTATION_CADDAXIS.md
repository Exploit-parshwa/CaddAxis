# Project Quotation: CaddAxis Institute Website

**Date:** December 30, 2025
**Project:** Educational Institute Website (Frontend + Dynamic Features)
**Total Estimate:** ₹40,000 INR

## Executive Summary
This quotation outlines the development costs for the CaddAxis Institute website. The project delivers a modern, high-performance, and responsive web application tailored for an educational institution. It includes a dynamic course catalog, student portal frontend, and an engaging user interface designed to convert visitors into students.

---

## Detailed Cost Breakdown

### 1. UI/UX Design & Core Architecture
**Cost: ₹10,000**
*   **Modern Visual Identity:** Implementation of a premium "Engineering Blue" & "Technical Gold" color scheme as per brand guidelines.
*   **Responsive Layout:** Fully responsive design ensuring perfect rendering on Mobiles, Tablets, Laptops, and Desktops.
*   **Modular Architecture:** Component-based structure (Header, Footer, Layouts) using PHP includes for easy maintenance and scalability.
*   **Typography:** Integration of Google Fonts (Oswald for headings, Inter for body) for a professional academic look.

### 2. Homepage Development (`index.php`)
**Cost: ₹8,000**
*   **Hero Section:** High-impact landing area with entrance animations and "Book Demo" CTA.
*   **Dynamic Stats Bar:** JavaScript-powered animated number counters (Students, Courses, Placement Rate) that trigger on scroll.
*   **"Why Choose Us" Section:** interactive layout highlighting key selling points (ISO Certification, Live Projects).
*   **Placement Partners:** Grid layout displaying hiring partners.

### 3. Course Management Module
**Cost: ₹12,000**
*   **Course Catalog (`courses.php`):** Dynamic grid system displaying various courses.
*   **Dynamic Header Navigation:** Advanced mega-menu in the header categorized by "Engineering CAD" and "Advanced Design" with auto-generated links.
*   **WhatsApp Integration:** (Ready-to-enable) Custom logic to pre-fill WhatsApp inquiry messages specific to each course (e.g., "I am interested in Revit...").
*   **Scalable Data Structure:** PHP array-based data handling allowing easy addition/removal of courses without editing HTML.

### 4. Student Portal Frontend
**Cost: ₹6,000**
*   **Auth System Design (`login.php`):** Dual-mode authentication interface.
*   **Interactive Toggles:** Smooth JavaScript transitions between "Sign In" and "Sign Up" views without page reloads.
*   **Form Validation:** Built-in HTML5 validation for emails, passwords, and phone numbers.
*   **Course Selection:** Integrated dropdowns for course interest during registration.

### 5. Utility Pages & System Optimization
**Cost: ₹4,000**
*   **404 Error Handling:** Custom designed 404 pages for "Franchise", "Events", and "Contact" to retain user retention even on missing pages.
*   **Performance Optimization:** CSS minification readiness and efficient asset loading.
*   **SEO Foundation:** semantic HTML5 structure, meta tags for descriptions, and proper heading hierarchy for better search engine ranking.

---

## Total Project Cost: ₹40,000 INR

### Value Additions (Included)
*   **Source Code Ownership:** Full access to unencrypted source code.
*   **Cross-Browser Compatibility:** Tested on Chrome, Firefox, and Edge.
*   **Future-Ready:** The PHP structure is designed to easily connect with a MySQL database in the future for backend functionality.
